# VOS TV Launcher

Android TV home-screen launcher (WebView + the VOS TV liquid-glass UI).

## Get the APK (no Android Studio needed)
1. Create a free GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab -> **Build APK** -> wait for the green check (about 4 minutes).
3. Open the finished run, download **VOS-TV-Launcher-APK**, unzip it to get `app-debug.apk`.
4. Put the APK on your TV (USB stick, or a "Send Files to TV" app) and install it.
   You may need to allow "Install unknown apps" for your file manager.

## Make it your Home screen
Install it, then press Home on the remote and pick **VOS TV** -> **Always**.
